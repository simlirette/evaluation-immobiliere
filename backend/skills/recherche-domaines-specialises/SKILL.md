# Skill : Recherche — Domaines spécialisés

## 1. Rôle et contexte

Ce skill encode les connaissances spécialisées des domaines verticaux qui impactent l'évaluation immobilière : expropriation, copropriété, patrimoine, financement, agriculture, énergie. **Chaque domaine exige un profil séparé (KQG-018) — ne pas traiter comme variante implicite du workflow principal.**

---

## 2. Connaissances encodées

### 2.1 Expropriation (Loi E-25, 2023)

**Indemnité** = valeur marchande + indemnités complémentaires :
- Valeur marchande (art. 85-86) : prix le plus probable, à la date d'expropriation, selon UMPP, marché libre
- Indemnité de déplacement, réaménagement, fermeture, concordance ou réinstallation (art. 84)
- Indemnité pour préjudices, perte de valeur de convenance, troubles

**Fardeau** : expropriant prouve la valeur marchande, exproprié prouve les autres éléments.

**Si usage autre que l'usage fait** → déduire coûts démolition et décontamination (art. 88).

### 2.2 Copropriété divise

**Obligations clés** :
- Assurance responsabilité : min. 1 M$ (< 13 fractions) / 2 M$ (≥ 13 fractions)
- Évaluation reconstruction par É.A. : tous les 5 ans
- Carnet d'entretien : obligatoire (règlement 2025, en vigueur 14 août 2025)
- Étude fonds de prévoyance : obligatoire tous les 5 ans
- Attestation état copropriété : requise lors de vente

**Impact évaluation** : état du fonds de prévoyance, carnet d'entretien, charges de copropriété, gestion du syndicat.

**Normes** : NPP OEAQ normes 13 et 14.

### 2.3 Patrimoine culturel (Loi P-9.002)

| Statut | Effet sur l'évaluation |
|--------|----------------------|
| Classé (ministre) | Autorisation requise travaux/vente, droit préemption, obligation entretien |
| Cité (municipalité) | Autorisation municipale, restriction démolition |
| Inventorié | Reconnaissance sans contrainte légale directe |

**Impact** : coûts rénovation majorés, restriction UMPP, subventions possibles, heritage premium potentiel.

### 2.4 Financement hypothécaire

**B-20 (BSIF)** — 5 principes : gouvernance, identité, capacité (ABD ≤ 39 %, ATD ≤ 44 %), valeur garantie, gestion risque.

**SCHL** — Assurance prêt : achat, amélioration (valeur telle quelle vs après travaux), immeuble locatif.

**Impact** : stress test réduit capacité d'achat → impact indirect sur prix marché. L'É.A. est le professionnel reconnu pour l'évaluation de la garantie.

### 2.5 Évaluation agricole

**Données FADQ 2024** : valeur moyenne terres agricoles 21 567 $/ha (+12,5 %). Terres en culture : 30 205 $/ha. Variation régionale : 2 000 à 41 000 $/ha.

**Facteurs** : usage, proportion culture, sol, drainage, accessibilité, localisation, disponibilité.

**Contrainte LPTAA** : zone agricole permanente → UMPP = usage agricole sauf autorisation CPTAQ.

### 2.6 Performance énergétique

**Réglementation RBQ** : isolation, fenestration, systèmes mécaniques, éclairage.

**Impact** : cote énergétique → coûts exploitation → valeur. Non-conformité → dépréciation fonctionnelle. Certifications (LEED, Novoclimat) → premium marché.

## 3. Méthodologie

### Étape 1 — Identifier le domaine spécialisé

Scanner le mandat pour détecter : expropriation, copropriété, bien patrimonial, financement, terre agricole, performance énergétique.

### Étape 2 — Appliquer le cadre réglementaire

Vérifier les lois et règlements applicables au domaine identifié.

### Étape 3 — Adapter les méthodes d'évaluation

Ajuster les méthodes pour refléter les contraintes spécialisées (restrictions UMPP, coûts additionnels, données spécifiques).

### Étape 4 — Documenter les particularités

Documenter toutes les contraintes et considérations spécialisées dans le rapport.

### Étape 5 — Vérifier KQG-018

S'assurer qu'un profil spécialisé séparé est créé si le dossier touche l'assurance, le fonds de prévoyance ou l'expropriation.

---

## 4. Règles critiques

1. **Profil spécialisé séparé** (KQG-018) pour expropriation, assurance copropriété, fonds prévoyance
2. **JAMAIS** utiliser les moyennes FADQ comme valeur directe d'une terre spécifique
3. **TOUJOURS** vérifier le statut patrimonial (classé, cité, inventorié) et ses contraintes
4. **TOUJOURS** considérer l'état du fonds de prévoyance en copropriété
5. **En zone agricole LPTAA** : l'UMPP est généralement l'usage agricole — ne pas supposer développement
6. **En expropriation** : la valeur marchande est définie par la Loi E-25, pas par le droit commun seul
7. **Stress test B-20** : impact indirect sur les prix, pas de modification de la valeur marchande intrinsèque
8. **Performance énergétique** : vérifier les normes en vigueur à la date d'évaluation
9. **Copropriété** : normes OEAQ 13 et 14 applicables, évaluation reconstruction aux 5 ans
10. **Patrimoine** : les contraintes peuvent avoir un impact positif (heritage premium) ou négatif (coûts)

## 5. Checklist de qualité

- [ ] Domaine spécialisé identifié et cadre réglementaire vérifié
- [ ] KQG-018 vérifié : profil séparé créé si applicable
- [ ] Contraintes légales documentées (LPTAA, P-9.002, E-25, CCQ copropriété)
- [ ] Impact sur l'UMPP évalué
- [ ] Données spécialisées utilisées (FADQ, CPTAQ, registre patrimoine)
- [ ] Méthodes d'évaluation adaptées au domaine
- [ ] Coûts additionnels considérés (rénovation patrimoniale, mise aux normes énergétique)
- [ ] État du fonds de prévoyance vérifié (copropriété)
- [ ] Sources spécialisées identifiées et fiables
- [ ] Particularités documentées dans le rapport
