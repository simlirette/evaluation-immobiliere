# Analyse — Vérification de conformité

> Synthèse exhaustive du processus de vérification de conformité d'un dossier d'évaluation immobilière contre les normes CUSPAP, NPP OEAQ, le Code de déontologie, les 18 gates KQG et les signaux de risque disciplinaire.

---

## 1. Architecture de conformité

### 1.1 Trois couches normatives

| Couche | Source | Force | Prévalence |
|--------|--------|-------|-----------|
| **Lois provinciales** | LFM, CCQ, Code des professions | Obligatoire | Absolue |
| **Normes professionnelles** | CUSPAP 2026, NPP OEAQ, Code de déontologie | Obligatoire pour les membres | En cas de conflit avec IAAO |
| **Standards internationaux** | IAAO, IPMS | Consultatif | Subordonnés aux lois et normes |

### 1.2 Règles coercitives vs directives (NPP OEAQ)

- **Règles coercitives** : obligatoires, aucune dérogation possible
- **Règles directives** : peuvent être modifiées avec l'accord du client et explication au rapport

## 2. Les 18 gates KQG (Knowledge Quality Gates)

### 2.1 Gates P0 — Bloquants (12 gates)

| Gate | Domaine | Vérification |
|------|---------|-------------|
| **KQG-001** | Mandat et identité | Client autorisé, utilisateurs, usage, objet, but, définition/source valeur, dates |
| **KQG-002** | Work-file | Manifest existant avant signature, rapports/drafts, certification, hashes, rétention |
| **KQG-003** | Scope et inspection | Inspection, limites, recherches, analyse, sources, fiabilité. Absence = justification extraordinaire |
| **KQG-004** | Validation IA/AVM | Interdire conclusion finale basée uniquement sur IA/AVM. Confirmation humaine obligatoire |
| **KQG-005** | Hypothèses et réserves | Type, impact, source, justification, statut de revue. Écarts aux directives = consentement client |
| **KQG-006** | Certification et signature | Aucun rapport final sans certification signée par l'évaluateur. Aucune signature automatique |
| **KQG-007** | Indépendance et conflits | Questionnaire obligatoire. Conflit non résolu = bloquer. Conflit autorisable = divulgation + consentement |
| **KQG-008** | Confidentialité | Chaque export déclare destinataire et base d'autorisation. Photos occupant = consentement |
| **KQG-009** | Consentement client | Client informé ampleur/modalités. Changement scope = nouveau consentement |
| **KQG-010** | Tiers essentiels | Déclaration avant usage, rôle, étendue, compétence, impact sur rapport |
| **KQG-011** | Méthodologie | Plus d'une méthode considérée si pertinent. Méthode unique = justification |
| **KQG-012** | Réconciliation | Revue processus, droits, date référence, indications valeur, raisonnement analytique |

### 2.2 Gates P1 — Importants (5 gates)

| Gate | Domaine | Vérification |
|------|---------|-------------|
| **KQG-013** | Examen/revue | Si revue activée : complétude, données, méthodes, techniques, analyses, conclusions |
| **KQG-014** | Rôle municipal vs marché | Donnée municipale ≠ conclusion valeur marchande sans analyse indépendante |
| **KQG-015** | Dossier municipal | Module séparé : mutations, dossier propriété, unités voisinage, SIG |
| **KQG-016** | Proportion médiane | Ventes admissibles vs privées, rajustements, exclusions, épuration |
| **KQG-017** | Signaux disciplinaires | Rapport incomplet, conclusion prédéterminée, explications insuffisantes, incohérence |

### 2.3 Gate P2 — Spécialisés (1 gate)

| Gate | Domaine | Vérification |
|------|---------|-------------|
| **KQG-018** | Verticaux spécialisés | Assurance, fonds prévoyance, expropriation = profils séparés, pas variantes implicites |

## 3. Éléments CUSPAP à vérifier

### 3.1 Rapport (CUSPAP 7.3, 7.4)

16 éléments obligatoires du rapport :
1. Identité de l'évaluateur
2. Client identifié
3. Utilisateurs autorisés
4. Objet de l'évaluation
5. Type et définition de la valeur
6. Date effective de l'évaluation
7. Date du rapport
8. Description de l'immeuble
9. Description de la portée des travaux
10. Hypothèses et conditions limitatives
11. Information sur l'inspection
12. Approche(s) utilisée(s) et analyse
13. Usage le meilleur et le plus profitable
14. Réconciliation et conclusion de valeur
15. Certification
16. Pièces jointes et annexes

### 3.2 Work-file (CUSPAP 5.8)

- Doit exister avant et simultanément à l'émission du rapport
- Conservation 7 ans minimum
- Contenu : rapports/brouillons, certification, données de support, traces
- Le stockage en ligne seul ne satisfait pas l'exigence

### 3.3 Confidentialité (CUSPAP 5.9)

- Protection des renseignements confidentiels du client
- Divulgation seulement aux personnes autorisées
- Consentement requis pour photos d'occupants

### 3.4 Indépendance (CUSPAP 5.10)

- Questionnaire conflit/indépendance au mandat
- Divulgation de tout conflit potentiel
- Pas de rémunération conditionnelle à la conclusion de valeur

### 3.5 IA/AVM (CUSPAP 7.5.1.viii)

- Aucune conclusion finale basée uniquement sur une sortie IA/AVM
- L'évaluateur reste responsable de la crédibilité des résultats
- Traces de corrections et validation humaine obligatoires

## 4. Éléments NPP OEAQ à vérifier

### 4.1 Norme 1 — Standard d'évaluation

- Éléments 1-4 : identification du mandat
- Élément 5 : portée des travaux
- Éléments 10-12 : méthodologie, méthodes, réconciliation
- Règle 1.1 : conformité aux normes
- Règle 1.2 : application correcte des méthodes
- Règle 2.2 : format de rapport approprié
- Règle 2.3 : justification du rejet d'une méthode

### 4.2 Norme 2 — Standard de rapport

- Rapport compréhensible et non trompeur
- Informations essentielles présentes
- Niveau de détail approprié au type de rapport

### 4.3 Normes 3-4 — Examen et revue

- Si revue activée : processus documenté
- Examinateur juge complétude, données, méthodes, conclusions

### 4.4 Norme 5 — Consultation

- Collecte, vérification et analyse des données
- Analyse complète du marché
- Options pour le client
- Informations essentielles

## 5. Signaux de risque disciplinaire (KQG-017)

### 5.1 Signaux à détecter

| Signal | Description | Sévérité |
|--------|-------------|----------|
| Rapport incomplet | Éléments obligatoires manquants | Élevée |
| Conclusion prédéterminée | Valeur fixée avant l'analyse | Critique |
| Explications insuffisantes | Méthodologie ou rejet non justifiés | Élevée |
| Absence informations essentielles | Données clés manquantes du rapport | Élevée |
| Incohérence de méthode | Erreurs dans l'application des méthodes | Élevée |
| Évaluations contradictoires | Même bien, valeurs divergentes sans justification | Critique |
| Signature rapport tiers | Rapport préparé par un non-membre | Critique |
| Non-visite ancienne | Aucune visite récente documentée | Élevée |

### 5.2 Actions

- Signal détecté → flag obligatoire dans le rapport de conformité
- Signal P0 → bloquer la finalisation du rapport
- Signal P1 → revue humaine obligatoire
- Tout signal → documentation et recommandation corrective

## 6. Dossier normalisé — Blocs requis

| Bloc | Champs requis |
|------|--------------|
| `mandate` | client, utilisateurs, usage, objet, définition valeur, dates, format, profil |
| `scope_of_work` | inspection, limites, recherches, analyse, sources, fiabilité |
| `data_sources` | id, type, rôle, fiabilité, limites, provenance tiers |
| `ai_use` | outil, tâche, hash, usage rapport, validation humaine, corrections |
| `assumptions_conditions` | type, texte, source, impact, divulgation client/rapport, statut |
| `methodology` | méthodes considérées, utilisées, rejets justifiés, étendue recherches |
| `reconciliation` | indications, droits, date effective, raisonnement, valeur finale |
| `work_file` | manifest, artefacts, drafts, certification, rétention, hashes |
| `certification` | identité, rôle, date, statut signature, hash rapport |
| `conflict_check` | questionnaire, résultat, divulgation, consentement |

## 7. Pièges et limites

- La conformité formelle ne garantit pas la qualité de l'évaluation
- Les règles directives NPP sont modifiables mais l'écart doit être consenti et documenté
- Le statut GO_CONTRATS_RUNTIME / NO_GO_PRODUCTION signifie que les gates sont définis mais pas encore testés en production
- Aucune conformité CUSPAP/OEAQ ne peut être déclarée sans validation humaine par un évaluateur agréé
- Les standards IAAO sont consultatifs — ne pas les traiter comme des obligations
