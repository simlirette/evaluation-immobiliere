# Analyse — Rédaction de l'analyse de marché

> Synthèse exhaustive de la structure, du contenu et des règles de rédaction des sections d'analyse de marché dans un rapport d'évaluation immobilière, incluant les descriptions de secteur, les études de marché et les rapports de consultation immobilière.

---

## 1. Objectif de l'analyse de marché

L'analyse de marché documente le contexte économique, géographique et immobilier dans lequel se situe la propriété évaluée. Elle sert à :
- Justifier les paramètres retenus dans les méthodes d'évaluation
- Démontrer la connaissance du marché par l'évaluateur
- Étayer les ajustements des comparables
- Fonder l'opinion de l'UMPP
- Contextualiser la conclusion de valeur

---

## 2. Composantes de l'analyse de marché dans le rapport d'évaluation

### 2.1 Description de la ville / municipalité

**Contenu** :
- Portrait général : population, économie, services gouvernementaux, institutions
- Positionnement régional : pôle urbain, desserte, axes de transport
- Attraits : patrimoine, culture, tourisme, infrastructures récréatives
- Dynamisme économique : industries, employeurs, diversification
- Qualité de vie : services, environnement, accessibilité

**Règle** : Pertinente et factuelle. Ne pas reproduire du contenu promotionnel sans lien avec la valeur immobilière.

### 2.2 Description du secteur immédiat

| Élément | Contenu attendu |
|---------|----------------|
| Localisation | Intersection/repères, positionnement dans la ville |
| Âge du quartier | En années (± X ans) |
| Type de quartier | Résidentiel, mixte, commercial, industriel |
| Tendance | En voie d'amélioration / stable / en déclin |
| Offre | Bonne / passable / faible |
| Demande | Bonne / passable / faible |
| Conformité du sujet | Bonne / passable (par rapport au quartier) |
| Homogénéité | Bonne / passable / faible |
| Accessibilité | Bonne / passable / éloigné |
| Voisinage | Type dominant de propriétés |
| Facteurs favorables | Proximité services, transport, attractions |
| Facteurs défavorables | Éloignement, nuisances, contraintes |

### 2.3 Proximité des services

Services à documenter avec distance/disponibilité :
- Dépannage
- Supermarché
- Centre commercial
- École
- Loisirs
- Parc
- Transport en commun

### 2.4 Marché immobilier local

| Indicateur | Valeurs types |
|-----------|--------------|
| Propriétés à vendre/louer à proximité | Aucune / quelques-unes / plusieurs |
| Délai de vente | < 3 mois / 3-6 mois / 6-9 mois / > 9 mois |
| Offre/demande | En équilibre / déséquilibrée |
| Type de marché | Acheteurs / vendeurs / équilibré |
| Variation terrain | À la hausse / stable / à la baisse |
| Variation loyer | À la hausse / stable / à la baisse |
| Variation coût construction | À la hausse / stable / à la baisse |
| Variation taux d'intérêt | À la hausse / stable / à la baisse |
| Tendance court terme | À la hausse / stable / à la baisse |
| Tendance moyen terme | À la hausse / stable / à la baisse |

### 2.5 Données municipales

| Champ | Description |
|-------|-----------|
| Numéro matricule | Identifiant foncier |
| Années du rôle | Triennal (ex. 2022-2023-2024) |
| Date du marché | 1er juillet de l'année précédant le dépôt (ex. 1er juillet 2020) |
| Proportion médiane | Ratio prix vente / évaluation municipale (%) |
| Évaluation terrain | Valeur inscrite au rôle ($) |
| Évaluation bâtisse | Valeur inscrite au rôle ($) |
| Évaluation totale | Terrain + bâtisse ($) |
| Taxes municipales | Montant annuel ($) |
| Taxes scolaires | Montant annuel ($) |
| Taxes totales | Municipales + scolaires ($) |

**Note explicative** : Le rôle d'évaluation foncière sert au financement des services municipaux et scolaires. Les valeurs reflètent le marché à la date du marché, non à la date actuelle. L'évaluateur municipal inclut l'ensemble des droits (faisceau des droits vs situation contractuelle).

### 2.6 Zonage

- Numéro de la zone
- Usages permis
- Conformité de l'usage actuel
- Droits acquis si usage non conforme
- Référence au règlement de zonage

## 3. Rapport de consultation immobilière (analyse de marché autonome)

### 3.1 Structure type observée (D-REEL)

Un rapport de consultation immobilière spécialisé en analyse de marché suit une structure plus élaborée :

| Section | Contenu |
|---------|---------|
| Introduction | Contexte, portée de l'étude, livrables, sources, terminologie, conditions limitatives |
| Description du projet | Localisation, description sommaire, aires projetées, échéancier |
| Paramètres économiques | Contexte général, faits économiques régionaux, prévisions démographiques, perspectives emploi |
| Analyse du marché | Inventaire, taux d'inoccupation historique, évolution offre/demande, commentaires |
| Corrélations | Emploi-absorption, emploi-construction, offre-demande-prix |
| Analyse prospective | Projections, scénarios, impact du projet analysé |
| Conclusions | Synthèse, recommandations |

### 3.2 Sources de données pour l'analyse de marché

| Source | Type de données |
|--------|----------------|
| Rôle d'évaluation municipale | Valeurs, caractéristiques, mutations |
| Bureau de la publicité des droits (BPD) | Transactions, actes, servitudes |
| JLR (registre foncier) | Historique transactions, prix déclarés |
| MLS / Centris | Inscriptions, prix demandés, délais vente |
| ISQ (Institut de la statistique du Québec) | Démographie, emploi, IPC |
| SCHL | Mises en chantier, taux vacance, loyers moyens |
| Municipalité | Zonage, permis de construction, plans d'urbanisme |
| Enquêtes privées (Desjarlais Prévost, CBRE, JLL) | Marchés de bureaux, commerciaux, industriels |

## 4. Indicateurs de marché

### 4.1 Indicateurs résidentiels

- Nombre de ventes par période
- Prix médian / prix moyen
- Délai de vente moyen
- Ratio prix vente / prix demandé
- Taux de vacance
- Loyers moyens par type
- Mises en chantier
- Absorption nette

### 4.2 Indicateurs commerciaux / bureaux

- Inventaire total (pi²)
- Taux d'inoccupation (global, par classe A/B/C)
- Loyer moyen demandé (brut, net)
- Absorption nette
- Nouvelles constructions / projets en cours
- Taux de capitalisation (TGA) du marché

### 4.3 Indicateurs industriels

- Inventaire total (pi²)
- Taux d'inoccupation
- Loyer moyen ($/pi²)
- Ventes récentes ($/pi²)
- Absorption nette

### 4.4 Indicateurs terrain

- Prix au m² ou au pi² par secteur
- Volume de transactions
- Tendance des prix
- Disponibilité des terrains

---

## 5. Analyse des tendances

### 5.1 Court terme (0-12 mois)

- Indicateurs actuels du marché
- Transactions récentes
- Inscriptions en cours
- Conditions économiques immédiates

### 5.2 Moyen terme (1-3 ans)

- Projections économiques
- Projets de développement annoncés
- Évolution démographique
- Changements réglementaires prévus

### 5.3 Long terme (3+ ans)

- Tendances structurelles
- Grands projets d'infrastructure
- Dynamique démographique
- Contraintes environnementales

---

## 6. Règles de rédaction

### 6.1 Objectivité

- Données factuelles et vérifiables
- Sources identifiées
- Pas de spéculation sans fondement
- Distinction entre faits et opinions

### 6.2 Pertinence

- Centré sur le type de propriété évalué
- Échelle géographique appropriée (quartier, ville, région)
- Période temporelle pertinente
- Indicateurs adaptés au segment de marché

### 6.3 Structure

- Tableaux pour les données comparatives
- Graphiques pour les tendances (si rapport complet)
- Sources en note de bas de page
- Données datées (mois/année)

### 6.4 Intégration au rapport d'évaluation

L'analyse de marché doit servir directement :
- L'UMPP : justifier l'usage retenu par les données du marché
- Les ajustements : dériver les ajustements temporels du marché
- Le TGA : extraire le taux du marché pour la méthode du revenu
- La réconciliation : contextualiser les indications de valeur

---

## 7. Pièges et limites

- Les données municipales ne sont pas des conclusions de valeur marchande — elles sont établies à une date antérieure pour des fins de taxation
- La proportion médiane mesure l'écart entre les prix du marché courant et les valeurs au rôle — elle n'est pas un facteur d'ajustement direct
- Les statistiques agrégées (prix moyen, médian) masquent la diversité des segments
- L'analyse de marché doit être actualisée — des données de plus de 12 mois peuvent être obsolètes
- La corrélation entre indicateurs économiques et valeurs immobilières n'est pas toujours directe
- Les prévisions sont des estimations — les qualifier comme telles
- Ne pas confondre offre (nombre de propriétés disponibles) et demande (nombre d'acheteurs actifs) avec les prix
