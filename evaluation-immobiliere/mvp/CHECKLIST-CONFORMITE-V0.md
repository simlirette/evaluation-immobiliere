# Checklist conformité v0 (pré-MVP)

## 1) Métadonnées dossier
- [ ] ID dossier présent
- [ ] Date de référence présente
- [ ] Type de mandat explicite
- [ ] Portée et limites du mandat documentées

## 2) Traçabilité des sources
- [ ] Chaque conclusion est liée à au moins une source
- [ ] Source datée et identifiable
- [ ] Aucune hypothèse sans justification textuelle

## 3) Approches d'évaluation
- [ ] Approche comparative: comparables justifiés
- [ ] Approche coût: hypothèses coûts et dépréciation explicites
- [ ] Approche revenu: RNE, taux et hypothèses documentés

## 4) Contrôles bloquants
- [ ] Aucune section obligatoire manquante
- [ ] Incohérences d'unités traitées
- [ ] Incohérences de dates traitées
- [ ] Statut final défini (`BROUILLON`, `A_REVOIR`, `PRET_REVISION_FINALE`)

## 5) Validation humaine
- [ ] Ajustements sensibles validés par évaluateur
- [ ] Réconciliation finale validée par évaluateur
- [ ] Signature/révision professionnelle enregistrée
