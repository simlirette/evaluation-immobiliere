# Ticket P0-05

## Contexte
P0-05 lance une mini-campagne de calibration terrain pour confirmer l’acceptabilité métier du scoring.

## Objectif mesurable
Documenter les écarts IA/évaluateur et faire signer les seuils Go/No-Go calibration.

## In scope / Out of scope
- In: collecte retours évaluateurs, analyse écarts, décision calibration.
- Out: extension massive panel clients.

## Entrées requises
- `evaluation-immobiliere/atelier/BACKLOG-EXECUTION-PRIORISE.md`

1. Compiler réponses évaluateurs.
2. Exécuter calibration scoring.
3. Documenter écarts et causes.
4. Obtenir décision signée métier.

## Critères d’acceptation (Given/When/Then)
- Given les réponses évaluateurs collectées, When `calibrer_reponses_evaluateurs_v0.py` est exécuté, Then la matrice d’écarts est générée sans blocage.
- Given la matrice d’écarts, When le comité métier statue, Then les seuils Go/No-Go sont signés et archivés.
